# 使用指南

**Vibe Learn Anything** 让 AI 为你把任何主题做成一门系统的互动课程，然后像在 Ed、Canvas 上一样学习：
章节、页面、练习、代码、进度、笔记——再加上一条直通 AI 的反馈回路。

## 1. 得到一门课程

**用 AI 生成**（首页 → 用 AI 生成课程）：

1. 软件会在 `文档/VibeLearn` 准备好「AI 工作区」：里面有给 AI 看的 `generate_course.md`、AI 手册和打包工具。
2. 在你常用的 AI 智能体里打开这个文件夹，把软件给你的提示词发给它。
3. AI 会**先问你问题**（想学什么、基础怎样、有多少时间、电脑上装了什么……），确认大纲后再生成课程。
4. AI 把课程打包到工作区的 `out/` 后，软件会自动弹出「导入」提示。

> 如果在「设置 → AI」里填了**交互式智能体命令**，可以直接在软件内置的终端里和 AI 对话生成课程。

**导入现成的课程**：把 `.vla` 文件拖进窗口，或点「导入 .vla」。

## 2. 学习

- **课程页**：按单元（Week 0、Week 1…）列出章节；✓ 已完成、● 进行中、○ 未开始；右侧是截止时间和完成页数。
- **学习页**：左边是本章页面列表，顶部是「课程 / 专注模式 / 上一页 / 下一页」，右边是「AI 修改 / 高亮 / 编辑」。
  - 快捷键：:kbd[Alt] + :kbd[←] / :kbd[→] 翻页，:kbd[Ctrl] + :kbd[Shift] + :kbd[H] 高亮模式，:kbd[Ctrl] + :kbd[E] 编辑，:kbd[Ctrl] + :kbd[`] 终端。
- 答对本页测验、或通过代码测试时，页面自动标记完成；普通页面在页尾点「标记为完成」。
- **页面列表右键**：标记为已完成 / 未完成、重置这一页的进度、删除这一页（会先确认）。
- 测验、填空、代码排序、记忆卡片右上角的 ↺ 可以重新作答。
- 只有一个 `:::fullscreen` 块的页面会铺满整个阅读区，适合整页的代码练习、PDF 和幻灯片。

## 3. 高亮与注释

**快速高亮**：选中文字 → 小气泡里选颜色，或「问 AI」「请 AI 修改」。

**高亮模式**（课程栏右侧「高亮」）：

1. 在右上角工具条选荧光笔：四种颜色（自己的笔记）、**问 AI**、**请 AI 修改**。
2. 拖选所有想标的文字（可以选很多段）；每个组件（测验、代码、PDF、图片……）下面会出现「标记这个控件」。
3. 点右上角绿色的 ✓，在右侧面板写注释。

**注释是一段对话**：你写的注释作者是 `learner`，AI 的回答作者是 `answer`。
点击任何高亮都能继续追加、编辑、删除注释，按住注释左边的 ⋮⋮ 拖动排序，也可以换荧光笔或标记为已解决。

## 4. AI 助教

标题栏右上角的 **✦ AI**（:kbd[Ctrl] + :kbd[Shift] + :kbd[A]）打开右侧的 AI 助教面板。它**知道你正在看哪里**：当前页面、你选中的文字、代码工作区里的代码，都会以小标签的形式附在输入框上方（点 × 就不附带）。

- 一门课一段对话，可以连续追问；右上角 ✎ 开始新对话。
- 打开输入框下方的「**允许修改课程**」后，AI 可以直接改写、补充这一页，甚至新建页面；页面会**实时刷新**。每次修改下面都有「修改了 N 个文件 · 撤销」。
- 课程栏右侧的「**AI 修改**」= 打开面板并允许修改本页。
- 代码工作区右上角「提示」左边的 **AI**：带上你的代码提问、解释代码、只给提示地帮你找错、修改这道练习，或者把整个工作区标记给 AI。编辑器右键菜单里也有「问 AI」。

**用哪个 AI**：装了 **Claude Code** 就直接用它（命令行版，或 Claude 桌面版自带的那一份都行），不需要额外的接口或密钥；第一次使用时在「设置 → AI」或面板里点「登录 Claude Code」。没有 Claude Code 时，也可以在设置里配置 OpenAI 兼容接口或其他命令行智能体（这两种只能问答，不能实时修改课程）。

**MCP**：软件自带一个 MCP 服务器（vibe-learn）。在软件里调用 Claude Code 时会自动接入；在「设置 → MCP」里一键把它加到 Claude Code 或 Claude 桌面版，就能在那边直接读写你的课程、看到你此刻打开的页面。

## 5. 让 AI 处理你的笔记

- **立即问 AI**：在「问 AI」的注释面板里点「立即问 AI」，答案直接写进对话（需要在设置里配置 AI）。
- **交给 AI 智能体处理**：课程页 → AI 菜单。智能体会在课程文件夹里回答所有「问 AI」、按「请 AI 修改」改进课程，完成后课程自动刷新。
- **导出给 AI**：生成带着你全部笔记的 `.vla` 和一段提示词，发给任何 AI；它处理完打包回来，软件提示导入，你的笔记和进度会合并保留。

## 6. 代码

- 代码块的「运行」按钮在你的电脑上执行代码（第一次会询问是否信任这门课）。
- 代码工作区：多文件编辑（VS Code 同款编辑器）、底部真终端、「提交」运行测试、提示和参考答案。代码自动保存在课程里。
- **Node.js 是内置的**；C、Python、Java 等需要你自己安装，课程页会提示缺少的工具。

## 7. 编辑课程

课程栏右侧的 ✎（:kbd[Ctrl] + :kbd[E]）进入编辑：像 Typora 一样直接在页面上改文字，改完自动保存。默认只能改文字，测验、代码、PDF 等控件是锁住的。

需要改控件时，在「设置 → 外观 → 源码编辑模式」打开后，✎ 会打开左右分屏的源码编辑器：左边是这一页的 Vitent Markdown，右边实时预览，语法错误会标红，:kbd[Ctrl] + :kbd[S] 保存。也可以直接让 AI 助教改。

## 8. 设置

- **外观**：深色 / 浅色 / 跟随系统，中文 / English，字号，源码编辑模式。
- **AI**：Claude Code（自动查找、登录、模型、默认是否允许修改课程）；MCP 服务器一键添加；其他 AI：OpenAI 兼容接口（密钥加密保存在本机）、命令行智能体命令。
- **代码运行**：终端 shell、Python 命令、检测到的工具。
- **安全**：已信任的课程，可以随时撤销。

课程、笔记和进度都保存在本机（设置 → 关于 → 数据文件夹），导出 `.vla` 就能备份或分享。
